# How to Run

You only need Docker installed.

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/farouqsallam/ecomerce-api-spring.git
    cd roka-ecommerce
    ```

2.  **Run the app:**
    ```bash
    docker compose up --build
    ```

3.  **Open Swagger UI:**
    http://localhost:8080/swagger-ui/index.html

4.  **Stop the app:**
    ```bash
    docker compose down
    ```
